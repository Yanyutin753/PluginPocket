## 实现边界

- 文件 API 响应在读入时限制45MiB（包含base64膨胀），先检查 Content-Length，未知长度使用 take(limit+1)；解析后解码全部文件并检查 SHA256、长度、路径、总量、SKILL.md UTF8，之后才写。
- 旧 inline 文本与旧服务 files 字符串兼容；file_manifest 存在必须读 files API，不能静默使用旧 inline 快照。
- 沿用原子写、符号链接拒绝及托管目录校验；只恢复普通文件执行位，不执行附件。跨文件事务、并发恶意文件系统变更及旧版嵌套目录卸载行为不在本次范围。
- 使用锁内已有 `base64 = 0.23.1`、`ring = 0.17.14`；官方 API 文档：<https://docs.rs/base64/0.23.1/base64/>、<https://docs.rs/ring/0.17.14/ring/digest/index.html>。没有手写摘要或base64算法。
- 全量 `make check` 由主任务执行；本子任务未进行Windows原生权限验证，Unix权限测试在WSL真实文件系统通过。
