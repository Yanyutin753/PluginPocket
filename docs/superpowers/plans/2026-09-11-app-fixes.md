# 账号、团队与管理写入边界修复

2026-09-11。当前工作区已获授权的修复；保留原有改动，不提交、推送、重启服务或操作真实客户端配置。范围为 `server/internal/app`（不修改 reports.go）和跨 app/identity 复用的 `auth/rate_limit.go`。

## 验收与设计

- 钱包、团队、工具、账号、兑换码、套餐的锁等待结束后，重新核验 Cookie 会话、账号启用状态和管理员角色。鉴权查询使用新语句的数据库时间，不使用事务开始时间或节点时间。
- 团队资金转入还在钱包锁后核验；兑换先锁兑换码与钱包再核验。团队令牌创建在团队锁后核验。套餐、兑换码创建、团队创建/接受邀请和设备批准通过事务内最终核验保证慢请求体或写锁等待后的撤销不会留下副作用。
- 工具 PATCH 在同一事务内锁行、读取 kind/config、校验、更新。省略 config 使用获得行锁后的当前值，避免覆盖已提交凭证轮换。
- builtin 输入 schema 复用 gateway 导出的官方 SDK AddTool 校验，保存前拒绝无法注册的 schema。
- 设备兑换取得行锁后以独立 SQL 重新比较数据库时间，已过期返回 expired_token，不签发令牌。
- 匿名认证按请求族和真实 RemoteAddr peer 隔离，忽略不可信转发头；每 peer/family 120 次/分钟，family 全局 1200 次/分钟，沿用 PostgreSQL 原子固定窗。错误 method 不消费预算。反代/NAT 后共享 peer 仍共享限制，当前没有可信代理地址配置。
