# Loadout Product Implementation Plan

> **For agentic workers:** 使用 subagent-driven-development 分模块执行，持久化 RED/GREEN 与审查记录；用户已授权当前工作区连续实现，不重复询问执行方式，不自动提交/推送。

**Goal:** 实现文档中的账号、MCP 接入、额度运营、团队与多端产品，完整验收。

**Architecture:** Go 模块化单体 + PostgreSQL 18.6；React 响应式控制台；Rust 共享接入库供 CLI/Tauri 使用。以事务账本、官方 MCP SDK 和真实集成测试保证正确性。

**Tech Stack:** 现有固定 React/Go/Rust 工具链；pgx v5.11.0、MCP Go SDK v1.7.0、x/crypto v0.57.0、Rust rmcp 3.2.0；其他新增库在使用前核验并精确固定。

**Spec:** ../specs/2026-09-10-product-design.md

## Global Constraints

- PostgreSQL 是唯一生产数据库，不能用内存/SQLite 替代集成测试。
- Web 深色、手机/平板/桌面功能一致；不使用浏览器自动化验证。
- 用户选择兑换码/管理员充值，外部支付保留接入边界。
- 所有行为按可编译空壳 → 断言 RED → 最小实现 GREEN → 回归；配置由真实工具消费。
- 用户的真实 HOME、客户端配置、既有数据库和远程分支不变。
