# 管理员系统配置与热更新

用户要求把适合热更新的环境配置放入前端系统配置页。本次在已有账户管理中增加 `/admin/settings`，仅管理员访问。

首批支持注册赠送额度、GitHub 登录开关/Client ID/Client Secret/组织限制、SMTP 开关/地址/发件人/用户名/密码。数据库和 Redis 连接、监听端口、公开源、加密主密钥、管理员引导账户、stdio 执行白名单和私网上游策略仍由部署环境配置，页面说明需重启，不展示其秘密值。

运行时配置持久化到 PostgreSQL 单行版本化记录。环境变量仅作为尚未保存时的默认值；保存后的新请求从数据库读取，以保证多副本立即看到一致配置，不使用本机 `.env` 改写或进程内可变指针。当前已执行的请求使用其开始时的快照；重启保留数据库配置。

管理员 GET 返回公开字段、版本和密钥是否已设置；不返回密钥原文。PATCH 提交版本和表单值，省略 secret 保留既有值，显式空值清除；启用集成时完整验证字段。密钥使用现有 AES-GCM helper 与部署加密主密钥加密后存储。没有密钥时允许无秘密的业务配置保存，拒绝保存非空秘密。公开源缺失时拒绝启用 OAuth/邮件；不放宽 SMTP 本地明文模式或网关私网限制。

写入使用事务和单行锁/初始化锁，版本冲突返回409，避免覆盖另一管理员更新。持久化写入后、提交前重新验证管理员会话和角色；记录更新管理员与时间。GET/PATCH 使用既有 Cookie 管理员鉴权及同源保护，数据库故障返回可重试5xx。

接入点：密码注册领取额度、GitHub注册/登录、邮件状态与发送、公开 `/meta`。不因配置请求失败而回退过时值或返回虚假保存成功。修改GitHub配置时正在进行的OAuth可能需要重新发起；每次HTTP请求使用一致配置快照。

前端采用既有 shadcn/Field/Input/Button、TanStack Query、Zod、双语目录与 AdminOnly；保存期间禁用提交，成功回显版本，失败保留输入。冲突提示重新加载；错误重试、键盘操作和秘密不回显均通过组件测试。后端测试覆盖匿名/普通用户/异源/过期会话拒绝、非法配置、秘密加密、省略保留、版本冲突、多实例读取以及新注册额度实际生效。最后运行 `make check`，不声称 DOM 验证代替移动/桌面视觉验收。
